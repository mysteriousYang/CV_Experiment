# 2024 南京邮电大学 计算机视觉基础 实验一

## 实验目的

1.	掌握OpenCV-Python的安装和环境配置；
   
2.	熟悉Numpy基础知识和操作函数；

3.	掌握图像读取、显示、噪声图像的生成；

4.	掌握基于一阶导数算子和二阶导数算子的边缘检测算法的使用；

5.	掌握Harris角点算法的使用；

6.	了解SIFT兴趣点检测算法的使用。

## 实验内容

1、从网络上下载一幅喜欢的图像（jpg或png格式），读取并显示这幅图像；

2、对该图像添加高斯噪声，将结果存储为一幅新图像；

3、对原始图像使用Sobel一阶导数算子分别提取x和y方向的梯度，并利用两个方向的梯度求取整幅图像的梯度，绘图显示三幅结果图像（x方向的边缘检测结果、y方向的边缘检测结果、整幅图像的边缘检测结果）；

4、对第2步存储的噪声图像直接使用Laplacian二阶导数算子提取图像边缘；对经过高斯滤波处理后的噪声图像使用Laplacian二阶导数算子提取图像边缘，绘图显示两幅结果图像（噪声图像的边缘检测结果、滤波图像的边缘检测结果）；

5、对原始图像分别进行缩放、旋转、添加高斯噪声，然后使用Harris算子进行角点检测，绘图显示四幅结果图像（原始图像的角点检测结果、缩放图像的角点检测结果、旋转图像的角点检测结果、噪声图像的角点检测结果）；

6、对原始图像分别进行缩放、旋转、添加高斯噪声，然后使用SIFT算子进行兴趣点检测，绘图显示四幅结果图像（原始图像的兴趣点检测结果、缩放图像的兴趣点检测结果、旋转图像的兴趣点检测结果、噪声图像的兴趣点检测结果）。
