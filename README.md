# 2024 南京邮电大学 计算机视觉基础 实验三

## 实验目的

1.	掌握图像分类的工作流程；
   
2.	掌握k近邻分类算法的应用；
   
3.	掌握朴素贝叶斯分类算法的应用；
   
4.	掌握多层感知机算法的应用；
   
5.	掌握支持向量机算法的应用；
   
6.	掌握随机森林算法的应用；
   
7.	掌握已有的深度神经网络模型的加载和使用方法；
    
8.	熟悉人脸识别的过程。

## 实验内容

1、学习示例代码“3.1 knearest-cv2.py”和“3.1 knearest-sklearn.py”，该两段代码分别用OpenCV的ML模块和sklearn库实现了手写字符数据集“digits.png”的k近邻分类。请用画图软件或手写拍照的方式自己制作手写数字测试图像，并用训练好的模型进行测试，展示数字识别结果；

2、参考并修改示例代码，对Olivetti Faces人脸数据集 “olivettifaces.png”进行k近邻分类，并输出分类准确率（备注：该图像由400张人脸合成，图像大小为940×1140。每一行包含人脸20个，每一列包含人脸20个。每个人的人脸图片为10张，包含正脸、侧脸以及不同的表情，每张人脸区域的尺寸为47×57）；

3、修改示例代码，对Olivetti Faces人脸数据集进行朴素贝叶斯分类，并输出分类准确率；

4、修改示例代码，使用多层感知机对Olivetti Faces人脸数据集进行分类，设置不同的隐藏层神经元个数和激活函数训练模型，计算并输出不同超参数设置下的测试集分类准确率；

5、修改示例代码，使用支持向量机对Olivetti Faces人脸数据集进行分类，采用至少三种不同的核函数训练模型，计算并输出不同核函数设置下的测试集分类准确率；

6、修改示例代码，使用随机森林对Olivetti Faces人脸数据集进行分类，采用不同数目的随机树训练模型，计算并输出不同超参数设置下的测试集分类准确率；

7、学习示例代码“3.7 lenet5.py”，该段代码基于PyTorch深度学习框架，实现了基于LeNet-5的手写字符识别任务，请用训练好的模型对自制的手写数字图像进行测试，展示数字识别结果。

8、参考示例代码，自行设计并实现一个带残差连接和批标准化的卷积神经网络，对Olivetti Faces人脸数据集进行分类，并输出分类准确率。请用文字和图片详细说明模型的结构及每个模块的功能。
