# 2024 南京邮电大学 计算机视觉基础 实验二

## 实验目的

1.	掌握自动阈值分割算法的应用；
   
2.	掌握Canny边缘检测算法的应用；
   
3.	掌握分水岭算法的应用；
   
4.	掌握K-均值图像聚类算法的应用；
   
5.	掌握Mean Shift图像聚类算法的应用。

## 实验内容

1、从网络上下载一幅喜欢的图像（建议图中只包含目标和背景两类），读取并显示这幅图像；

2、将该图像转换为灰度图像，编写函数实现如下的迭代自动阈值算法，对图像进行阈值分割，绘图显示结果图像；

3、将该图像转换为灰度图像，对图像添加高斯噪声，采用Otsu自动阈值算法对图像进行阈值分割；对添加高斯噪声的图像先进行高斯滤波，再采用Otsu自动阈值算法对图像进行阈值分割；绘图显示结果图像（噪声图像、无滤波的阈值分割结果、滤波后的阈值分割结果）；

4、将该图像转换为灰度图像，采用Canny边缘检测算法提取图像边缘，设置不同的高低阈值组合，验证阈值大小对图像边缘检测效果的影响；通过高斯滤波处理原始图像再进行Canny边缘检测，对比高斯滤波前后图像的边缘检测效果，绘图显示结果图像（不同阈值的边缘检测结果、高斯滤波前后的边缘检测结果）；

5、参考帮助文档中的案例https://docs.opencv.org/4.1.2/d3/db4/tutorial_py_watershed.html#/ ，对图像进行分水岭分割，并绘图显示中间结果及最终分割结果；

6、采用cv2.pryMeanShiftFiltering函数对一幅彩色图像进行MeanShift平滑聚类，然后利用Canny边缘检测算法提取图像边缘，绘图显示结果图像（MeanShift聚类结果图像、边缘检测结果图像）。

7、采用cv2.kmeans函数对一幅彩色图像进行K-均值聚类，然后利用不同颜色填充聚类区域，绘图显示结果图像（K均值聚类结果图像、填色结果图像）。
